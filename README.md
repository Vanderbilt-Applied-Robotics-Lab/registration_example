# registration_example
In-class example for Arun's method


## Downloading Code
1. Navigate to examples workspace source folder: `cd ~/workspaces/examples_ws/src`
2. Download code: `git clone https://github.com/Vanderbilt-Applied-Robotics-Lab/registration_example.git`

## Compiling Code
1. Navigate to examples workspace: `cd ~/workspaces/examples_ws`
2. Compile the code: `colcon build`

## Running Code
1. Navigate to the examples workspace: `cd ~/workspaces/examples_ws`
2. Source the examples workspace: `source install/setup.bash`
3. Run the code: `ros2 run arun_reg arun_reg`

## References
K. S. Arun, T. S. Huang and S. D. Blostein, "Least-Squares Fitting of Two 3-D Point Sets," in IEEE Transactions on Pattern Analysis andMachine Intelligence, vol. PAMI-9, no. 5, pp. 698-700, Sept. 1987, doi:10.1109/TPAMI.1987.4767965
